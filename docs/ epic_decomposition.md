Декомпозиция бизнес-эпика Каталог (SwiftUI)
Ссылка на таск-трекер: https://github.com/users/Victorr-r/projects/1/views/1
Архитектурный паттерн: MVVM
Способ вёрстки: SwiftUI
Ключевые требования: iOS 17.0+, Swift Concurrency (async/await, actor, @MainActor)


Итерация 1. Часть 1: Верстка экранов по Figma (UI Layer)

	•	Задача 1.1: Разбор макета Каталога в Figma и создание структуры папок в Xcode согласно паттерну MVVM. Оценка: 1 ч 30 мин 
	•	Задача 1.2: Верстка главного экрана каталога (List и ячейка с обложкой, названием и счетчиком NFT). Оценка: 3 ч 30 мин 
	•	Задача 1.3: Верстка экрана коллекции (верхняя обложка, описание, имя автора и сетка LazyVGrid для товаров). Оценка: 4 ч 
	•	Задача 1.4: Верстка ячейки NFT для сетки (картинка, звезды рейтинга, цена в ETH, кнопки лайка и корзины). Оценка: 2.5 ч 
	•	Задача 1.5: Создание Pull Request из ветки этапа в ветку эпика и отправка на Ревью №1. Оценка: 30 мин 


Итерация 2. Часть 2: Кнопки, сортировка и открытие сайтов (Presentation Layer)

	•	Задача 2.1: Интеграция веб-вью через UIViewRepresentable для открытия сайта автора по клику на его имя. Оценка: 2 ч 30 мин 
	•	Задача 2.2: Создание ViewModels для управления экранами и обработки действий пользователя. Оценка: 3 ч 
	•	Задача 2.3: Реализация кнопки сортировки на главном экране (по умолчанию — по количеству NFT). Оценка: 1.5 ч 
	•	Задача 2.4: Локальное сохранение выбранной сортировки через @AppStorage (чтобы настройки восстанавливались после перезапуска). Оценка: 2 ч 
	•	Задача 2.5: Логика переключения иконок в ячейке: лайк (сердечко) и добавление в корзину (смена на крестик). Оценка: 2 ч 
	•	Задача 2.6: Создание Pull Request, проведение кросс-код-ревью внутри команды и отправка на Ревью №2. Оценка: 30 мин 


Итерация 3. Часть 3: Подключение к сети и Swift Concurrency (Data & Integration)

	•	Задача 3.1: Создание потокобезопасных Sendable/Decodable моделей под JSON-ответы мокового сервера. Оценка: 2 ч 
	•	Задача 3.2: Реализация сетевого сервиса (actor) для безопасной работы с данными в многопоточной среде. Оценка: 3 ч
	•	Задача 3.3: Написание асинхронных запросов через async/await для скачивания списков коллекций и NFT. Оценка: 3.5 ч 
	•	Задача 3.4: Связывание сети с UI и добавление индикатора загрузки ProgressView на время ожидания ответа. Оценка: 1.5 ч 
	•	Задача 3.5: Проверка утечек памяти, отлов багов с потоками (@MainActor) и финальная сборка через Git Fork. Оценка: 2.5 ч 
	•	Задача 3.6: Создание финального Pull Request и отправка на Ревью №3. Оценка: 30 мин
